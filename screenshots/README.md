# Responsive proof screenshots

Capture the dashboard at these exact viewport widths and replace the placeholder images in this folder:

- `mobile-320px.png` — 320 × 800 or similar mobile viewport
- `tablet-768px.png` — 768px wide tablet viewport
- `desktop-1024px.png` — 1024px wide desktop/tablet viewport
- `wide-desktop-1440px.png` — 1440px wide desktop viewport
- `dark-mode.png` — any desktop/tablet width with dark mode enabled

The layout is designed to remain usable between these checkpoints as well.
